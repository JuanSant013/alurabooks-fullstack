# AluraBooks

Projeto Full Stack desenvolvido durante a formação da Alura. O projeto consiste em um site de livros, utilizando React no frontend e Node.js com Express no backend para criar e consumir uma API.

## 🚀 Tecnologias utilizadas

- React
- Node.js
- Express
- Styled Components
- Axios

## 📚 Habilidades praticadas

- Criação de componentes React
- Gerenciamento de estado com React
- Utilização de Props
- Estilização com Styled Components
- Desenvolvimento de APIs REST com Express
- Criação de rotas
- Manipulação de dados em JSON
- Tratamento de erros
- Consumo de APIs com Axios
- Integração entre frontend e backend
